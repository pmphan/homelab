# Homelab

NixOS configuration, deployed from a flake.

## Features

- **Impermanence:** Root is wiped on every boot, except for data explicitly allowed to persist.
- **Snapshots:** Filesystem is btrfs and is snapshotted periodically via `btrbk`.
- **Encryption:** Disk is encrypted and unlocked on boot via SSH into the initrd.
- **Auto-deploy:** Host periodically polls this repo and switch to the new commits with `comin`.
- **Tailscale:** Host is reachable over the tailnet, with Tailscale SSH.

## Layout

    flake.nix               inputs, the host list, the dev shell
    machines/<host>/        per-host facts: disko, facter, homelab.* settings
    modules/system/         boot, disk, network, deploy
    modules/services/       what the homelab serves
    modules/users/          accounts
    secrets/                sops-encrypted, decrypted by the host key

## Usage

Deploy:

    nixos-rebuild switch --flake .#host --target-host user@host --sudo --ask-sudo-password

Unlock after a reboot:

    ssh -p 2222 root@host
    systemd-tty-ask-password-agent

Check the config:

    nix flake check

Roll back:

    ssh user@host sudo nixos-rebuild switch --rollback

Deploy state:

    ssh user@host comin status

Tailnet state:

    ssh user@host tailscale status

## Installation

Two keys have to exist before installation: The host key sops decrypts with, and the key the initrd serves the unlock prompt with.

    keys=/tmp/key-files
    install -d -m 755 $keys/persist/etc/ssh $keys/persist/etc/secrets/initrd
    ssh-keygen -t ed25519 -N '' -f $keys/persist/etc/ssh/ssh_host_ed25519_key
    ssh-keygen -t ed25519 -N '' -f $keys/persist/etc/secrets/initrd/ssh_host_ed25519_key

Derive the host key's age recipient and put it in `.sops.yaml` under the host's anchor:

    ssh-to-age -i $keys/persist/etc/ssh/ssh_host_ed25519_key.pub

Write the host's secrets:

    sops secrets/host.yaml

```yaml
users:
    pmphan: <mkpasswd -m sha512crypt>
```

Or re-encrypt the existing file:

    sops updatekeys secrets/*.yaml

The LUKS passphrase:

    printf '%s' 'the-luks-passphrase' > /tmp/luks.key

Install:

    nixos-anywhere --flake .#host --target-host root@192.168.1.10 \
      --extra-files $keys \
      --disk-encryption-keys /tmp/cryptroot.key /tmp/luks.key \
      --generate-hardware-config nixos-facter machines/host/facter.json

Then clear what is left behind:

    rm -rf $keys /tmp/luks.key

If the machine configures Tailscale, the tailnet has to be joined manually:

    ssh user@host sudo tailscale up

## Hardwares

`machines/*/facter.json` is generated by `nixos-facter` and read by `hardware.facter`. Refresh with the `--generate-hardware-config` flag, or add `pkgs.nixos-facter` to the running machine:

    ssh user@host 'sudo nixos-facter' > machines/host/facter.json

`homelab.host.nicModules` need to be derived manually:

    ssh user@host 'basename "$(readlink -f /sys/class/net/<iface>/device/driver)"'
